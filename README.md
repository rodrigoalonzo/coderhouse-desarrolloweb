e# coderhouse-desarrolloweb

Proyecto final para el curso de Desarrollo Web de Coderhouse

## Descripción

Sitio web estático creado con HTML, CSS y Sass. El proyecto aplica conceptos de estructura semántica, diseño responsive, estilos reutilizables y organización modular de hojas de estilo.

## Link Netlify

https://rodrigo-javier-alonzo.netlify.app/

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass
- JavaScript
- Node.js y npm

## Instalación

1. Clona el repositorio:

   ```bash
   git clone <https://github.com/rodrigoalonzo/coderhouse-desarrolloweb.git>
   ```

2. Ingresa a la carpeta del proyecto:

   ```bash
   cd coderhouse-desarrolloweb
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

## Compilación de Sass

Para compilar los archivos Sass a CSS y mantener la compilación activa durante el desarrollo, ejecutá:

```bash
npm run sass:watch
```

Este comando utiliza el script configurado en el archivo `package.json`.

## Estructura del proyecto

```text
├── pages/          # Páginas internas del sitio
├── recursos/       # Imágenes, íconos y recursos visuales
├── scss/           # Estilos fuente en Sass
├── styles/         # Archivos CSS compilados
├── index.html      # Página de inicio
├── package.json    # Dependencias y configuración del proyecto
└── README.md
```
