Proyectos

Algunos de mis proyectos

  • GestionPro — Sistema de gestión administrativa y facturación para comercios minoristas, con control de stock en tiempo real y reportes automáticos de ventas.
  • TurnosYa — Aplicación web para la reserva y administración de turnos, pensada para consultorios y estudios profesionales que necesitan optimizar su agenda diaria.
  • LogiTrack — Plataforma de escritorio para el seguimiento y control logístico de pedidos, diseñada para una pyme del rubro distribución con múltiples depósitos.
  • ClientFlow — CRM a medida para el seguimiento de clientes y oportunidades comerciales, con paneles de indicadores para la toma de decisiones.
